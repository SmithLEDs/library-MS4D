# 🔹 Функция `dayOfWeek`

> Возвращает номер дня недели для заданной даты.

---

## 📥 Входные параметры

| Параметр    | Тип    | По умолчанию | Описание                                   |
| ----------- | ------ | ------------ | ------------------------------------------ |
| `inputDate` | `DATE` | `1970-01-01` | Дата, для которой определяется день недели |
| `sun7`      | `BOOL` | `TRUE`       | `TRUE` — воскресенье считается выходным (7-й день) |

---

## 📤 Возвращаемое значение

| Параметр | Тип     | Описание         |
| -------- | ------- | ---------------- |
| `Q`      | `UDINT` | Номер дня недели |

---

## 📦 Зависимости

Отсутствуют.

---

## 📝 Примечания

- При `sun7 = TRUE` отсчёт начинается с **понедельника (1)** и заканчивается **воскресеньем (7)**.
- При `sun7 = FALSE` — **воскресенье (0)** … **суббота (6)**.


---

## 💡 Пример использования

```text
Q := dayOfWeek(DATE#2026-10-26, TRUE);
// Q = 1  (понедельник)
```
