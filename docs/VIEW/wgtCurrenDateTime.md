# 📅 Виджет `wgtCurrentDateTime`

> Визуальное отображение текущих даты, времени и дня недели.

![wgtCurrentDateTime](../../assets/VIEW/wgtCurrentDateTime/plashka_240x40.png)

---

## 📦 Зависимости

| Библиотека | Комментарий                                                                 |
| ---------- | --------------------------------------------------------------------------- |
| `ATOM`     | Цвета, шрифт                                                                |
| `FUNC`     | Функция [`dayOfWeek`](../FUNC/dayOfWeek.md) — вычисление дня недели         |

---

## 📝 Примечания

- Для получения текущей даты используется программа `getNowTime` на основе системной функции [`GET_TIME`](https://support.mps-soft.ru/Help-web/index.html?get_time.html).
- Способ исполнения: **периодический**.
- Рекомендуется назначить объекту отдельную задачу исполнения с периодом **1000 мс** — иначе виджет не будет обновляться с секундной точностью.
