# 📦 Библиотеки для MasterSCADA 4D

> Набор переиспользуемых библиотек, построенных по **атомарному принципу**: от низкоуровневых примитивов до готовых визуальных виджетов.

---

## ⚛️ ATOM — базовые примитивы

Базовая библиотека. Содержит атомарные элементы, из которых строятся все остальные слои.

| Категория          | Содержимое                          |
| ------------------ | ----------------------------------- |
| 🎨 Цвета           | Палитра проекта                     |
| 🔤 Шрифты          | Типографика                         |
| 🖼️ Иконки          | Базовые пиктограммы                 |
| 🧩 Типы данных     | Перечисления, структуры             |

---

## ⚙️ FUNC — логика

Библиотека функциональных блоков и функций. Не содержит визуальных элементов.

🔹 [`dayOfWeek`](docs/FUNC/dayOfWeek.md) - Возвращает номер дня недели для заданной даты.

---

## 🖥️ VIEW — визуальные виджеты

Готовые небольшие визуальные элементы: плашки, панели, виджеты отображения информации.

🔸 [`wgtCurrentDateTime`](docs/VIEW/wgtCurrentDateTime.md) - Визуальное отображение текущих даты, времени и дня недели.
